Keep an eye on every cook without leaving Homey. This app pairs directly with your ToGrill AT-02 BBQ thermometer over Bluetooth LE and streams live temperatures for up to four meat probes plus the grill's ambient sensor.

Set a target temperature for each probe and let Homey Flows notify you the moment it is reached, warn you if a probe disconnects, or react if the grill overheats. Everything runs locally over Bluetooth — no bridge, no cloud account, and no separate phone app required.
